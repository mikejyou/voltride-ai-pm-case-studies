# App Release Notes

## Version 4.2.0 — 14. Mai 2026
- Neuer Sperrmechanismus: Bestätigung des Abschließens jetzt mit haptischem Feedback
- Kartenansicht überarbeitet, Ladezeit um ca. 40 % reduziert
- Fotoupload beim Abstellen: Komprimierung serverseitig
- **Bekanntes Problem:** Auf Android 15 kann der Fotoupload zum Absturz führen. Fix in 4.2.1 geplant.

## Version 4.1.3 — 2. April 2026
- Fehlerbehebung: Fahrten wurden in Einzelfällen nicht korrekt beendet
- Studierendentarif im Tarifwechsel sichtbar

## Version 4.1.0 — 11. März 2026
- Pausenmodus eingeführt
- Registrierung: Führerscheinprüfung entfällt für E-Bikes bis 25 km/h

## Version 4.0.0 — 20. Januar 2026
- Vollständig neues App-Design
- Dark Mode **nicht** enthalten — für ein späteres Release vorgesehen, kein Termin
